## 安装或升级

```bash
curl -fsSL https://raw.githubusercontent.com/9star-academy/bakctl/v1.1.0-rc.2/scripts/install.sh -o /tmp/bakctl-install.sh
sudo env BAKCTL_VERSION=v1.1.0-rc.2 bash /tmp/bakctl-install.sh
bakctl --version
```

预期输出：`bakctl version v1.1.0-rc.2`。安装脚本先验证 `SHA256SUMS`，再替换已有程序；下载或校验失败保留原安装。RC 不会替换最新正式版本，安装时需显式指定版本。

发布文件包含 Linux amd64/arm64、macOS amd64/arm64 四个平台的二进制，以及 `SHA256SUMS`。

## 兼容与验收

- 从 v1.1.0-rc.1 升级无需迁移配置或备份。
- 新版能读取 v1 备份，旧版程序不能读取新版生成的备份；请保留可用于恢复的新版二进制与密码。
- 恢复目标必须是尚不存在的路径；PostgreSQL 恢复会生成 SQL 文件，需另行导入隔离数据库验收。
- SQLite 依赖 `sqlite3`，PostgreSQL 依赖兼容的 `pg_dump`，定时运行依赖 Linux systemd。
- 云存储、真实 PostgreSQL 与 Linux timer 仍需在实际部署环境验收。

发布前执行 `go test -race ./...`、`go vet ./...` 和安装脚本语法检查；GitHub Actions 执行 Linux/macOS CI 及四平台构建。升级后建议按 [验收指南](../testing.md) 完成一次备份与恢复演练。

上一版本的可靠性修复详见 [v1.1.0-rc.1 发布说明](v1.1.0-rc.1.md)。
